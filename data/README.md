# Datos y fuentes

Esta carpeta reúne los datos del proyecto y la documentación de dónde salen.

## Reglas

- Toda fuente se registra en la tabla de abajo: origen, condiciones de uso y fecha de acceso.
- Los datos sintéticos se guardan en `synthetic/` y su nombre empieza con `synthetic_`. Nunca se presentan como datos reales.
- No se suben datos personales ni de salud reales.
- Antes de usar una fuente, se revisan sus condiciones de uso. Los sitios que no son del gobierno de EE. UU. tienen sus propios términos.
- Los archivos pesados descargados de terceros no se versionan: se citan con su enlace (ver `.gitignore`).
- Para optar a un premio global hay que usar datos o recursos de la NASA. Se indica cuáles y cómo se usaron.
- Cualquier dato, código, texto o imagen de terceros se lista con su autoría y licencia, aunque sea de libre uso.

# Data and sources (English)

This folder holds the project data and documents where it comes from.

## Rules

- Every source is logged in the table above: origin, terms of use and access date.
- Synthetic data lives in `synthetic/` and its file name starts with `synthetic_`. It is never presented as real data.
- No real personal or health data is committed.
- Before using a source, its terms of use are reviewed. Non-U.S. Government sites have their own terms.
- Large third-party downloads are not versioned: they are cited by link (see `.gitignore`).
- To be eligible for a global award, NASA data or resources must be used. The project states which ones and how.
- Any third-party data, code, text or image is listed with its authorship and license, even if freely available.
